# 제품 가치와 확장 로드맵

## 해결하려는 사용자 문제

기존 농업 정보 서비스는 사용자가 병명을 어느 정도 알고 직접 검색해야 하는 경우가 많습니다. 잎파라치는 이 과정을 다음 흐름으로 단순화합니다.

```text
작물 선택·촬영
→ 병변 자동 탐지
→ 질병 후보 분석
→ 병변 위치 시각화
→ 출처가 있는 관리·예방 정보
→ 날씨와 작물 관리 정보
```

핵심 가치는 “AI가 병명을 맞히는 것” 하나가 아니라, 전문지식이 없는 사용자도 스마트폰으로 1차 판단 정보를 얻고 다음 행동을 결정할 수 있게 하는 것입니다.

## 제품 차별점

- 전체 사진 분류에 그치지 않고 병변 위치를 마스크로 표시
- 하나의 결과를 확정하지 않고 Top-K 후보와 신뢰도를 활용
- 사용자가 선택한 작물로 비전 후보와 RAG 근거를 함께 제한
- 공공 농업 자료를 연결해 증상·원인·관리 방법을 제공
- 출처와 필수 필드를 검사한 구조화 결과 반환
- 별도 전용 장비 없이 Android 스마트폰에서 사용

## 예상 사용자

- 농업인과 귀농·도시농업 사용자
- 농업기술센터와 현장 상담 인력
- 스마트팜 및 농업 플랫폼
- 종자·비료·농자재·작물보호제 기업
- 농업 교육·연구 기관

## 서비스 확장 방식

### B2C

기본 사진 진단과 질병 사전을 제공하고, 이후 진단 이력 장기 보관, 병변 진행도, 농장별 작물 관리, 지역별 위험 알림으로 확장할 수 있습니다.

### B2B/API

분할·분류·근거 검색 엔진을 API로 제공하면 기존 농업 플랫폼이나 스마트팜 서비스가 처음부터 비전 모델을 개발하지 않고 진단 기능을 연결할 수 있습니다. 이 경우 고객사가 가진 방제·농자재 정보와 결과를 연결할 수 있습니다.

## 단계별 로드맵

1. AI 모델과 모바일 앱 프로토타입 완성 — **현재 구현 범위**
2. 실제 농가 환경의 독립 데이터로 성능 검증
3. 병변 면적 정량화와 진단 이력 기능
4. 농가·전문가 실증 및 Gold set 구축
5. 기업용 API와 모델/인덱스 버전 관리
6. 농업 플랫폼과 PoC
7. 운영 모니터링·개인정보·약제 규정을 반영한 상용화

## 장기 확장 아이디어

- 병변 면적 변화에 따른 진행도 분석
- 해충과 영양장해 탐지
- 생육 단계와 상품성 분석
- 스마트팜 고정 카메라 모니터링
- 드론·농업 로봇 영상 분석
- 지역·시기별 병해 발생 지도와 위험 예측

## 상용화 전에 해결해야 할 조건

- 작물·지역·계절을 분리한 현장 검증
- 전문가 검수와 책임 범위 표시
- 등록 약제·방제 정보의 시점별 갱신
- 사용자 촬영 이미지의 동의·보관·삭제 정책
- 낮은 신뢰도와 미지원 질병을 거절하는 OOD 처리
- API 고객별 데이터 분리와 운영 보안
