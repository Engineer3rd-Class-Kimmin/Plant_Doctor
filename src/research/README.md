# Research scripts

포트폴리오 검토에 필요한 대표 스크립트만 선별했습니다.

- `100_train_segformer_field_aug_v5_1.py`: 환경 증강과 SegFormer 학습
- `101_benchmark_random_field_aug_v5_1.py`: 분할 성능 벤치마크
- `21_train_lesion_classifier.py`: ConvNeXt-Small 질병 분류 학습
- `104_build_nongsaro_evidence_gated_rag.py`: 근거 중심 RAG 구축
- `117_plant_er_nongsaro_dual_scope_harness_host_locked.py`: host-aware 검색·진단 하네스
- `129_audit_rag_source_traceability.py`: 출처 추적성 감사
- `130_patch_rag_provenance_v6_5.py`: provenance 보강
- `131_activate_latest_rag_v6_5_1.py`: 최종 RAG 활성화 검사

스크립트에는 원 개발 환경의 절대 경로가 남아 있을 수 있습니다. 공개본은 설계와 구현 검토를 위한 코드 샘플이며, 데이터/가중치 없이 그대로 실행되는 완전 재현 패키지는 아닙니다.
